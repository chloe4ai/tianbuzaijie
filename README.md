## 音频怎么来的

三版均由 [ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5)（MIT）在本地 Apple Silicon 上生成，
未使用任何在线音乐服务。词、编曲方案、画面为原创。

三版响度对比（主歌 → 末段副歌）：

| 版本 | 主歌 | 末段副歌 | 落差 |
|---|---|---|---|
| v1 | −19.0 dB | −14.7 dB | 4.3 dB |
| v2 | −21.1 dB | −14.0 dB | 7.1 dB |
| v3 | −23.2 dB | −14.9 dB | 8.3 dB |

## 合成成片

```bash
./build.sh audio/v3.mp3
```

需要 `ffmpeg`，以及未收录进本仓库的 `天不再借_画面.mp4`（265 MB，超过 GitHub 单文件上限）。

## 歌词时间轴怎么来的

页面上的逐句时间**不是**编曲方案里的计划时间，而是从每个音频版本里**实测**出来的：

1. `transcribe.py` — 用 Whisper（mlx，本地）转写三版，取词级时间戳
2. `probe.py` — 对识别失败的区间，以已知歌词为提示做针对性重听
3. `align.py` — 忽略识别出的**文字**，只用**时间**：把已知的 30 句歌词与识别字流做全局动态规划对齐，
   再对每句的匹配字做线性回归外推出真实起唱点

结果（`cues.js` / `align_report.json`）：

| 版本 | 显示句数 | 实测锚定 | 推算 |
|---|---|---|---|
| v1 | 30 | 30 | 0 |
| v2 | 26 | 24 | 2 |
| v3 | 30 | 28 | 2 |

三版起唱时间差别很大：v3 在 27.6s，v1 在 36.7s，v2 在 44.2s。

**v2 未演唱桥段**：131.5–151.5s 的人声带能量为 3.91、调制度 0.79，与该版已知有唱段落（6.33 / 0.50）
不符，而与纯器乐段（4.06 / 0.65）一致。因此桥段四句在 v2 中不显示，而不是猜一个时间。
